# 中文自然化编辑

在事实和结构稳定后执行。目标不是把文章改成随意聊天，而是删掉机器式组织痕迹，让作者声音、专业度和读者关系自然。

## 第一遍：删“写给所有人”的空话

优先删除或改写：

- “在当今社会”“随着时代发展”“众所周知”“值得深思”；
- “此外”“与此同时”“值得注意的是”“不可否认”；
- “至关重要”“关键作用”“不断演变的格局”“持久影响”；
- “专家认为”“有观点指出”“行业报告显示”等无具体来源归因；
- “希望这对你有帮助”“如果需要请告诉我”等聊天残留；
- 模糊乐观结尾、挑战与未来展望、口号式升华。

简单事实用简单句。能写“是”“有”“可以”，不绕成“作为”“拥有……能力”“发挥……作用”。

## 第二遍：拆公式

- 减少“不仅……而且……”“不是……而是……”；
- 不为了完整强凑三项，真实需要两项或四项就照写；
- 避免每节都用“提出问题—三点分析—金句收尾”；
- 少用破折号、括号、连续感叹号和表情符号；
- 不机械使用“首先、其次、最后”；
- 不把每个列表项都写成“粗体小标题：解释”；能成段就成段；
- 不用同义词轮换回避正常重复，关键概念保持名称一致。

## 第三遍：补作者声音

- 允许明确判断、犹豫和边界，不装全知；
- 长短句交替，避免连续句子长度和结构相同；
- 抽象判断后接可感知的细节；
- 段尾不都写成可截图金句；有的收在事实，有的收在问题或具体动作；
- 第一人称只用于用户提供的真实经验或明确作者观点；
- 不为了“人味”虚构采访、亲历、情绪或场景；
- 幽默和锋芒必须符合账号口吻，不能把严肃议题娱乐化。

## 常见替换

- “值得注意的是，数据显示……” → “数据显示……”
- “系统具有处理的能力” → “系统可以处理”
- “在这个时间点” → “现在”
- “对行业格局产生深远影响” → 写出具体改变了谁、什么流程或哪项指标
- “这不仅是一款产品，更是一场革命” → 写出新增功能、使用变化和证据
- “专家普遍认为” → 给出具体专家、机构和材料；没有就删除
- “充满活力、丰富多彩、令人惊叹” → 写可观察的设施、活动、价格或体验

## 公众号专项检查

- 开头是否直接进入问题，而非向读者寒暄；
- 每段是否只有一个主要意思；
- 小标题是否有判断，而非“背景”“分析”“总结”；
- 是否过度加粗、划线或把每句话都做成金句；
- 是否用网络热词假装亲切；
- 是否把“读者都怎样”写成无来源共识；
- 文末是否只留一个自然、具体的问题，而非求赞求转的套话组合。

## 评分

每项 1—10 分，总分低于 42 时继续修改：

| 维度 | 10 分标准 |
|---|---|
| 直接性 | 不绕圈宣告，开门见山 |
| 节奏 | 长短句和段落收束有变化 |
| 具体性 | 判断落在数据、动作、场景或细节上 |
| 真实性 | 像一个有边界的人，不像新闻稿或百科 |
| 精炼度 | 没有可删的套话与重复 |

最后朗读关键段落。读起来拗口、整齐得不自然或处处像标语时，继续改。
