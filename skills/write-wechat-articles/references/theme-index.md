# 主题注册表

渲染主题的机器可读单一来源是 `assets/themes.json`。不要在正文 HTML 中临时发明另一套样式。

| 主题 | 适用内容 | 视觉特征 |
|---|---|---|
| `moyu-green` | 教程、清单、知识解释、生活方式 | 墨绿、米白、温和纸感，默认主题 |
| `red-white` | 观点评论、社会议题、热点拆解 | 红黑白、对比强、标题有冲击力 |
| `graphite-minimal` | 科技、商业、财经、职场、数据 | 石墨灰、克制、专业、信息密度高 |

`auto` 路由规则：

- 标题或正文含观点、争议、真相、反对、代价、被高估等词，选 `red-white`。
- 含 AI、科技、商业、数据、公司、职场、财经、法律等词，选 `graphite-minimal`。
- 其余选 `moyu-green`。

用户明确指定主题时尊重选择。主题只改变视觉，不改变文章内容。需要增加新主题时，复制 `assets/themes.json` 中一项，保持所有既有键，并运行仓库校验与三个主题的冒烟测试。
