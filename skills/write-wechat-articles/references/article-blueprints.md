# 文章结构路由

只读取并采用与任务匹配的结构。选择一个主类型，最多融合一个辅助类型。

## 观点评论

适合文化、职场、教育、社会现象、商业趋势。

结构：读者熟悉的看法 → 本文判断 → 证据与解释 → 最强反方 → 适用边界 → 结论。

验收：观点可反驳；反方不是稻草人；证据足以支撑标题强度。

## 知识解释或辟谣

适合科技、科学、健康、历史、政策常识。

结构：具体误解 → 准确定义 → 原理或证据 → 容易混淆的边界 → 读者如何判断。

验收：不把争议问题写成定论；解释了机制；给出可操作的判断方法。

## 教程与操作指南

适合工具、学习、职场、家居、创作、互联网。

结构：适用对象 → 前置条件 → 顺序步骤 → 示例 → 常见错误 → 验收标准。

验收：读者知道开始前准备什么、每步做什么、完成后如何检查；不把个人偏好写成唯一方法。

## 测评与购买决策

适合数码、汽车、软件、家电、消费和旅行产品。

结构：使用场景 → 评价标准 → 资料或实测条件 → 优缺点 → 适合谁／不适合谁 → 建议。

验收：注明型号、版本、价格日期、测试条件和利益关系；不以参数代替体验；明确代价。

## 案例复盘

适合运营、创业、项目、职业成长和商业。

结构：背景与目标 → 关键选择 → 结果 → 原因拆解 → 可复用经验 → 不可复制条件。

验收：结果来自真实记录；区分事实与事后解释；不能只复盘成功，不写成本和失败变量。

## 数据与趋势分析

适合经济、行业、市场、人口、体育和城市。

结构：先给结论 → 数据口径 → 变化 → 驱动因素 → 反例与限制 → 后续指标。

验收：写清分母、时间范围、样本和来源；不把相关当因果；避免只列百分比。

## 人物与故事特稿

适合人物、品牌、历史、社会和文化。

结构：有张力的真实场景 → 人物欲望或困境 → 关键事件 → 细节与转折 → 影响 → 克制结尾。

验收：场景和引语可核实；不用履历堆砌代替人物；不窥探与公共议题无关的私生活。

## 清单与资源盘点

适合书单、工具、路线、方法和产品。

结构：筛选标准 → 分类条目 → 每项用途与代价 → 避坑 → 快速选择建议。

验收：条目不是凑数；每项有选择理由；明确适用人群；商业关系已披露。

## 生活与情感随笔

适合个人观察、关系、生活方式和城市经验。

结构：具体场景 → 感受或困惑 → 细节展开 → 自我反驳或变化 → 留有余味的收束。

验收：只用用户提供的真实经历；不把个人体验泛化为群体规律；不强行升华。

## 常用冲突库

- 主流认知与可验证事实；
- 短期收益与长期代价；
- 个体体验与总体数据；
- 专业标准与大众感受；
- 效率与公平；
- 便利与隐私；
- 理想原则与现实执行；
- 商业成功与真实价值；
- 高价格与高价值；
- 传统经验与新技术；
- 个人努力与结构条件；
- 政策目标与落地效果；
- 品牌叙事与产品体验；
- 专家共识与网络流行说法；
- “人人适用”的建议与具体人群差异。
