# 公众号 Markdown 交接

## 正文规范

- `#` 只用于文章标题；`##` 用于 3—6 个主章节；`###` 仅在确有第二层结构时使用。
- 每段 2—5 句，连续长段主动拆分；列表只用于并列步骤、条件或选项。
- 引用块只放真实引语、引言或必须突出的整段判断。
- 代码、命令和 Prompt 使用围栏代码块；网址、代码和英文标识符以外使用中文全角标点。
- 最强锚点不超过 5 处，使用 `**加粗**`；主题下划线使用 `++短语++`；少量高亮使用 `==短语==`。
- 不整段加粗，不用表情符号装饰章节。
- 图片使用 `![准确说明](URL)`；没有链接时写 `【配图建议：画面内容｜作用｜版权提醒】`。

推荐顺序：`# 主标题` → 可选摘要或引言 → `##` 正文章节 → 结尾问题 → 可选署名。

作者未提供信息时，不擅自写死署名。需要占位时只在末尾保留一次：

```markdown
我是 {{作者名}}，{{一句话简介}}。
```

## HTML 前的内容锁定

开始排版前完成：

- 标题层级连续，没有多个 `#`。
- 每个 `##` 对应一个清楚分论点。
- 图片位于相关段落之后，alt 文本真实准确。
- 加粗、高亮和下划线没有滥用。
- 代码与 Prompt 没有混入普通段落。
- 半成品备注、聊天用语和内部核查说明不在正文中。
- 作者签名和 CTA 只有末尾一处。
- Markdown 正文与事实核查表分开。

锁定后，排版只能改变视觉呈现，不得重写事实、观点、引语或数字。
